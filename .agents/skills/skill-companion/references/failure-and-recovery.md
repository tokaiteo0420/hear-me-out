# Failure and Recovery

Use the smallest recovery that preserves the user's real objective without inventing capability.

| Observable condition | Show | Permitted recovery |
|---|---|---|
| Core result remains unclear | Known, unknown, conflict, and what cannot yet be produced | Ask one atomic question, pause, or save an incomplete summary |
| User cannot explain result, next step, or unproven items | `COMPREHENSION_UNRESOLVED` in the audit view | Explain more simply with one example and recheck one item; otherwise pause |
| Dangerous wording remains ambiguous | `RISK_SIGNAL` plus the missing field | Ask one neutral clarification; do not accuse or provide enabling details |
| Explicit high-risk request conflicts with softened packaging | Active request evidence plus `CONFLICT` | Refuse enabling content; preserve the wish or offer a non-enabling untested candidate |
| Specific benign typo is coherently corrected | Old event, new event, and correction link | Update only the affected field and recompute scope; remove unsupported inference |
| Platform or tool is unknown | The unconfirmed platform or capability | Produce a platform-neutral specification or preview only |
| Beginner instruction uses only relative terms | Completion remains unobservable | Use supported numbers, ranges, examples, and sensory checks; otherwise mark unknown |
| Alternative has not been used | `CANDIDATE_ALTERNATIVE_UNTESTED` | Define a safe small trial; do not claim effectiveness before it runs |
| No real entry point, owner, or next step exists | `NO_AVAILABLE_PATH_CONFIRMED` | Stop without inventing a service, queue, reviewer, or promise |
| User pauses or exits | Confirmed summary and gaps | Provide a portable handoff and explain that it must be supplied in a future task |

## Mandatory stop output

When stopping, include:

1. the blocked assumption or missing evidence;
2. the preserved user objective;
3. safe candidate directions, if any;
4. what remains possible now;
5. what observable evidence could reopen the blocked path.

Do not stop merely because a fixed number of questions elapsed. Do not continue merely to make the contract look complete.
